# Product Factory Workflow

1. Research market opportunity.
2. Freeze product specification.
3. Define structured content schema.
4. Prototype representative pages.
5. Build reusable renderer.
6. Generate complete product.
7. Validate educational content and layout.
8. Generate answer key from the same source data.
9. Export print-ready PDF.
10. Produce TPT listing assets and copy.
11. Publish and measure.
12. Improve, localize, and reuse.

## Cloud ownership

**Google Drive:** plans, research, product specifications, business documents and final review material.

**GitHub:** HTML/CSS/JS, structured data, language dictionaries, templates, technical documentation and version history.

**ChatGPT:** orchestration layer across both systems.
