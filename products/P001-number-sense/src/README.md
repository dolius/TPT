# P001 HTML prototype

Open `index.html` in a browser to review the first vertical slice.

Current prototype renders Days 1–3 as US Letter print pages and establishes reusable components for:
- circle the number
- count and write
- numeral/quantity matching
- represent a number
- ten frames

Use the browser Print dialog with Letter paper and 100% scale for PDF review.
